### C'est quoi « les tests UI cassés » ?

Ça ne concerne pas le MCP. Le projet Xcode contient deux sortes de tests :

- **les tests unitaires** (`OpenNotesTests`), qui vérifient la logique : lasso, gomme, post-it, synchro. Ils passent tous.
- **les tests UI** (`OpenNotesUITests`), qui pilotent l'app dans le simulateur comme un robot : « tape sur le bouton Select, puis sur Done… ». Beaucoup cherchent des boutons qui n'existent plus depuis qu'on a changé l'interface. Ils échouent donc alors que l'app marche.

Ce n'est pas un bug de l'app, c'est une suite de tests périmée. Comme tu testes toi-même sur l'iPad, on peut la laisser comme ça, ou supprimer les tests obsolètes un jour. Ce n'est pas urgent.
