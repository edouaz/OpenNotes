# Your first notebook

## Create and organize

Open the library and use the create button to name a notebook. Choose your paper, then open it. Use folders and favorites to organize your library; the list/grid control changes its layout. Open notebooks stay in tabs so you can switch between them.

## Write and edit

Choose the pen or highlighter in the editor toolbar. Tap the selected tool to adjust its settings. Enable finger drawing in your preferences if you are using a simulator or writing without Apple Pencil. Use two fingers to navigate when finger drawing is enabled.

Use the eraser for precision, segment or whole-stroke removal. Choose the lasso to select ink and page objects, then use its actions or handles to move, resize, rotate or copy the selection. Undo and Redo work on the current editing session.

Add text, images or a sticky note from the editor tools. After choosing a sticky note, tap the page to place it. The page counter opens navigation and reordering; add a page with the page control. Settings include the default page style, toolbar placement and battery saver.

## Bring a PDF

Import a PDF from the library, or share a supported file to OpenNotes using the iOS share sheet. Annotate its pages with the same writing tools. Search uses extracted PDF text; scanned documents may have no searchable text.

## Export and back up

Use the notebook menu to export a PDF for sharing, or an `.opennote` archive for an editable backup. Keep a separate copy outside the app before upgrading. Trash lets you recover deleted notebooks, but it is not an independent backup.

Legacy `.catnote` filenames are still recognized. That does not convert old PencilKit ink: open older PencilKit pages in the original build and export them there before upgrading. Keep the same signing identity and identifiers when updating; uninstalling can remove local data.

## Optional synchronization

Local notebooks work without an account. Account and sync controls connect to an optional configured Supabase backend. Follow the [sync guide](SUPABASE.md) before using it. Keep independent exports of important notebooks while connected features remain experimental.

For installation and signing, see the [developer guide](https://edouaz.github.io/OpenNotes/develop.html#install). Report a problem with your device, OS version and reproduction steps, using synthetic notes in screenshots.
